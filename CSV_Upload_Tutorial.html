CSV Upload Tutorial

Use this guide to edit schedule data safely and upload it to the website.

The four file types

Main Schedule

Controls the normal start and end times for each period on Monday through Friday.

Countdown

Controls countdown events such as breaks, quarter ends, and the end of the year.

Special Days

Controls no-school days, breaks, early releases, finals, and special weeks.

Period Text

Converts period codes such as WH or L into display names.

What each file contains

Main Schedule

Columns: Campus, Grade Level Category/Group, Days, Hour/Period, Start Time, End Time. All files use commas, and day lists containing commas must be quoted.

Campus,Grade Level Category/Group,Day/s of the Week(M,T,W,Th, and/or F),Hour/Period,Start Time (24 hr),End Time (24 hr)
    Vinland,High School,"M, T, Th",1,8:15:01,8:58

Countdown

Columns: Name, Campus, Grade Level Category/Group, Date, Time, Name in Spanish.

Name,Campus,Grade Level Category/Group,"Date (Month Day, Year)",Time (24 hrs), Name in Spanish
End of QTR 1,Vinland,High School,"October 16, 2026",15:25:00,Fin del trimestre 1

Special Days

Columns: Name, Campus, Grade Level Category/Group, Date/s, Hour/Period, Start Time, End Time, Name in Spanish.

Name,Campus,Grade Level Category/Group,Date/s (mm/dd/yyyy),Hour/Period,Start Time (24 hr),End Time (24 hr), Name in Spanish
Early Release,Vinland,High School,11/25/2026,Normal,8:15,12:00,Salida temprana

Period Text

Columns: Code, Text, Text in Spanish. The Code must match the Main Schedule period code.

Code,Text, Text in Spanish
WH,Warrior Hour,Hora del Guerrero
L,Lunch,Almuerzo

How to edit

  1. Make a copy of the matching example file.
  2. Keep the header row unchanged.
  3. Edit one row per schedule item or event.
  4. Use 24-hour times, such as 15:25:00 for 3:25 PM.
  5. Use the date format shown for that file type.
  6. Put quotation marks around any field containing commas.
  7. Save as a UTF-8 .csv file. All four files use comma-separated columns.

How to upload

  1. Open Settings, then open Schedule Data.
  2. Choose the matching type in CSV type to upload.
  3. Click Choose CSV File and select one CSV.
  4. The site saves it in this browser and reloads the schedule.
Important: Select the correct type before choosing the file. A Main Schedule CSV selected as Period Text will be rejected.

Which data wins?

  1. A valid uploaded CSV wins for its own type.
  2. For types without an upload, Local uses the bundled CSV files.
  3. For types without an upload, Global uses Google Sheets.
  4. If Google Sheets fails, the bundled local CSV is used.
  5. If an upload has an error, Local uses the bundled CSV and Global uses Google Sheets.

Uploads are stored in browser storage. They remain after closing and reopening the site on the same browser and device, but they are not shared with other devices.
